# 健康饮食记

「健康饮食记」是一个移动端高保真前端原型，定位为女生喜欢的可爱健康日记风 App。当前阶段只实现前端演示，不接真实后端和 AI 服务，所有识别结果与营养数据均为 mock 数据。

## 功能页面

- 启动页 / 引导页
- 今日饮食首页
- 拍照记录页
- AI 分析页
- 饮食日记页
- 营养报告页

## 技术栈

- React
- Vite
- lucide-react
- CSS glassmorphism / gradient UI

## 本地运行

```bash
npm install
npm run dev
```

## 检查

```bash
npm run lint
npm run build
```
