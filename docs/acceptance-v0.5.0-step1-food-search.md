# v0.5.0-step1 分析页食物库搜索验收记录

## 版本范围

- 分支：`wechat-miniprogram-mvp`
- 功能提交：`f5527c6 feat: add food item search for analysis`
- 目标：让用户在分析页确认识别结果时，可以通过云函数安全搜索 `food_items`，并把食物库营养数据带入本餐。

## 本步新增能力

- 新增云函数：`searchFoodItems`
- 分析页 `食物库添加` 不再直接读取数据库集合。
- 分析页通过 `wx.cloud.callFunction({ name: 'searchFoodItems' })` 搜索食物库。
- 搜索结果带入：
  - 食物名称
  - 分类
  - 图标
  - 每 100g 热量
  - 蛋白质
  - 碳水
  - 脂肪
  - 纤维
  - 默认克数
- 添加后用户仍可修改克数，页面会按每 100g 营养重新计算。

## 部署要求

必须在微信开发者工具里上传并部署新云函数：

1. 打开 `cloudfunctions/searchFoodItems`
2. 右键选择：`上传并部署：云端安装依赖`
3. 等待部署完成
4. 重新编译小程序

如果没有部署该云函数，分析页搜索会显示：

```text
食物库搜索失败，请确认 searchFoodItems 云函数已部署。
```

## 手动验收步骤

### 1. 基础搜索

1. 进入小程序 `记录` 页。
2. 上传或拍摄任意餐食图片。
3. 进入 `确认识别结果` 页面。
4. 点击 `食物库添加`。
5. 搜索 `牛肉`。
6. 应看到食物库中的牛肉相关结果。

### 2. 添加食物

1. 点击搜索结果中的 `牛肉`。
2. 牛肉应进入本餐食物列表。
3. 页面汇总热量、蛋白质、碳水、脂肪应更新。

### 3. 修改克数

1. 把牛肉克数从默认值改成 `200`。
2. 牛肉热量和本餐汇总应随克数变化。
3. 不应出现 `NaN`。

### 4. 搜索不存在的食物

1. 搜索一个不存在的关键词。
2. 页面应显示空状态，不白屏。
3. 用户仍可返回后使用 `手动添加`。

### 5. 保存验证

1. 保存本餐。
2. 首页今日摄入应更新。
3. 日记页应显示刚添加的食物明细。

## 当前限制

- 本步骤仍不接入外部视觉 AI。
- 搜索只读取已维护的 `food_items`。
- 如果食物库缺少某个食物，需要先在后台食物库新增。
- 搜索接口只读，不提供用户端新增食物能力。
