# v0.5.4 后台复核与反馈验收记录

## 版本范围

- 分支：`wechat-miniprogram-mvp`
- 阶段：`v0.5.2` - `v0.5.4`
- 目标：增强后台 AI 复核任务和用户反馈处理可用性，不影响用户端主流程。

## 已完成能力

1. AI 复核任务支持 `cancelled` 状态展示。
2. AI 复核任务支持“已取消”筛选。
3. 被用户删除餐食关联的复核任务，会显示“关联餐食已删除，任务已自动取消”。
4. 用户反馈卡片显示关联餐食上下文，包括餐食记录、分析记录、图片状态、餐次、记录时间、热量、识别来源和置信度。
5. 用户反馈卡片显示食物摘要，便于管理员理解问题来源。
6. 用户反馈管理支持状态筛选：全部、待处理、处理中、已处理、已关闭。
7. 用户反馈管理支持上一页 / 下一页分页。

## 验收步骤

1. 在微信开发者工具重新编译小程序。
2. 使用管理员账号进入：我的 -> 后台管理。
3. 打开 AI 复核任务页：
   - 切换“已取消”筛选。
   - 确认取消任务不显示“通过 / 拒绝”操作按钮。
   - 确认取消任务显示自动取消说明。
4. 打开用户反馈页：
   - 确认反馈列表正常显示。
   - 切换待处理、处理中、已处理、已关闭筛选。
   - 点击上一页 / 下一页，确认分页正常。
   - 对餐食问题反馈，确认能看到关联餐食上下文。

## 已知限制

1. 本阶段不新增复核详情页。
2. 本阶段不新增反馈详情页。
3. 反馈分页使用当前 `adminApi.listFeedback` 的 `page/pageSize/status` 参数。
4. 真实图片视觉 AI 仍未接入，当前识别仍以食物库和关键词 fallback 为主。

## 部署说明

本阶段只修改后台页面展示逻辑，不需要重新部署云函数。
