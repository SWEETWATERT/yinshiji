# v0.4.0 餐食记录全链路验收指南

## 版本范围

- 分支：`wechat-miniprogram-mvp`
- 阶段：`v0.4.0` 餐食记录真实链路一期
- 目标：用户可以记录一餐，系统完成关键词/食物库识别，用户确认修改后保存，首页和日记能读取真实数据，后台可查看低置信度复核任务。

## 当前功能清单

### 用户端

- 微信登录和用户资料读取仍沿用现有云函数链路。
- 记录页支持选择餐次、拍照/相册上传、备注输入，并进入分析页。
- 分析页支持读取 `analyzeMeal` 新返回结构：
  - `detectedFoods`
  - `candidates`
  - `recognitionSource`
  - `modelProvider`
  - `modelVersion`
  - `confidence`
  - `needReview`
  - `warnings`
  - `visionResult`
- 分析页支持用户确认识别结果：
  - 修改食物克数
  - 删除识别项
  - 手动添加食物
  - 实时重算本餐热量、蛋白质、碳水、脂肪、纤维
- 保存餐食时会写入：
  - `foods`
  - `detectedFoods`
  - `confirmedFoods`
  - `totalNutrition`
  - `total`
  - `recognitionSource`
  - `modelProvider`
  - `modelVersion`
  - `confidence`
  - `needReview`
  - `candidates`
  - `visionResult`
- 首页今日摄入、蛋白质、碳水、脂肪、纤维基于真实 `meal_records` 汇总。
- 日记页展示每餐真实明细，包括食物名称、克数、热量和识别状态。

### 后台端

- 后台首页、用户管理、餐食记录、AI 复核、食物库、用户反馈、系统配置已完成 v0.3.x 管理能力。
- 后台餐食记录可查看用户保存的餐食记录和营养数据。
- 低置信度或 `needReview=true` 的餐食保存后会创建或更新 `review_tasks`。
- AI 复核任务页支持管理员通过/拒绝任务。
- 食物库支持搜索、分页、新增、编辑、启用/停用。

## 当前识别链路

```text
记录页拍照/上传
  -> analyzeMeal 云函数
  -> visionAnalyze 占位层
  -> note + food_items 食物库匹配
  -> keyword fallback
  -> 分析页用户确认
  -> saveMealRecord 云函数保存
  -> meal_records / review_tasks
  -> 首页汇总 / 日记展示 / 后台查看
```

## AI 识别当前能力和限制

当前还不是真实视觉 AI 识别。

- `visionAnalyze` 是占位层，返回 `modelProvider: "placeholder"`，用于后续接入真实图片识别服务。
- 当前可用识别主要来自：
  - 用户备注关键词
  - `food_items` 食物库字段匹配
  - 内置 keyword fallback
- 图片已进入上传和传参链路，但图片内容尚未被真实视觉模型解析。
- 营养结果是估算值，必须由用户确认食物和重量后保存。
- 低置信度结果会进入后台人工复核队列，避免把不确定识别当作确定结论。

## 手动测试步骤

### 1. 食物库基础数据

1. 打开后台：`我的 -> 后台管理 -> 食物库`。
2. 搜索 `牛肉`，确认存在可用食物项。
3. 搜索 `白粥`，确认存在可用食物项。
4. 如果缺少食物，可在食物库新增后再测试。

### 2. 记录牛肉

1. 进入 `记录` 页。
2. 选择任意餐次，例如午餐。
3. 上传或拍摄图片。
4. 备注输入：`牛肉100克`。
5. 点击开始分析。
6. 分析页应显示牛肉识别项。
7. 将克数从 `100` 改成 `200`。
8. 确认本餐总热量和营养随之变化。
9. 点击保存。
10. 回到首页，今日摄入应增加。
11. 进入日记页，当前餐次应显示牛肉明细。

### 3. 记录白粥

1. 进入 `记录` 页。
2. 备注输入：`白粥200克`。
3. 分析页应显示白粥识别项。
4. 保存后，首页和日记页应能看到对应记录。

### 4. 手动新增食物

1. 在分析页点击 `手动添加食物`。
2. 输入食物名，例如 `鸡蛋`。
3. 输入克数，例如 `50`。
4. 如果没有匹配营养数据，该项营养可为 0，但页面不能崩溃。
5. 保存后日记页应能看到手动添加项。

### 5. 低置信度复核

1. 在分析页确认一个 `needReview=true` 或低置信度结果。
2. 保存餐食。
3. 进入后台 `AI复核任务`。
4. 应能看到对应复核任务，包含餐次、图片、备注、候选食物或确认食物。
5. 点击通过或拒绝，任务状态应更新。

## 已知问题

- 图片内容尚未接入真实视觉 AI，当前主要依赖备注关键词和食物库。
- 克数推断只能识别简单表达，例如 `牛肉100克`、`白粥200克`。
- 手动新增食物如果没有营养字段，营养值会按 0 保存。
- 不同食物库字段来源不完全统一，已做兼容，但仍需后续清洗数据。
- `review_tasks` 是人工复核辅助，不会自动修改已保存餐食记录。
- 真实上线前还需要完善隐私说明、用户授权说明和营养估算免责声明。
