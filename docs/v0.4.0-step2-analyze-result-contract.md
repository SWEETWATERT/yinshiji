# v0.4.0-step2 analyzeMeal 返回结构契约

## 目标

本阶段不接外部 AI，不改变前端页面和保存链路，只把 `analyzeMeal` 当前的关键词 / 备注 / `food_items` 匹配结果整理成稳定返回结构，为后续真实图片识别接入做准备。

## 调用方式

云函数：`analyzeMeal`

输入：

```json
{
  "imageFileID": "cloud://xxx/meal-images/example.jpg",
  "mealType": "lunch",
  "note": "米饭 鸡胸肉 西兰花 少油"
}
```

## 兼容保留字段

以下字段继续保留，现有 `pages/analyze` 可以继续读取：

```json
{
  "analysisId": "ana_...",
  "imageUrl": "cloud://xxx/meal-images/example.jpg",
  "detectedFoods": [],
  "total": {
    "kcal": 0,
    "proteinG": 0,
    "carbsG": 0,
    "fatG": 0,
    "fiberG": 0
  },
  "warnings": [],
  "aiAdvice": ""
}
```

## 新增统一识别字段

```json
{
  "recognitionSource": "keyword_fallback",
  "modelProvider": "mock_keyword",
  "modelVersion": "v0.4.0-step2",
  "confidence": 0.3,
  "needReview": true,
  "candidates": []
}
```

字段说明：

- `recognitionSource`：当前识别来源。本阶段固定为 `keyword_fallback`，表示由备注关键词和食物库匹配得出。
- `modelProvider`：当前识别提供方。本阶段固定为 `mock_keyword`。
- `modelVersion`：当前返回结构版本。本阶段固定为 `v0.4.0-step2`。
- `confidence`：整体识别置信度，范围为 `0.3` 到 `0.7`。
- `needReview`：当 `confidence < 0.6` 时为 `true`。
- `candidates`：识别候选食物数组，供后续真实视觉 AI 接入时复用。

## candidates 结构

每个候选食物尽量包含：

```json
{
  "foodId": "pro_chicken_breast",
  "nameCn": "鸡胸肉",
  "name": "鸡胸肉",
  "kcalPer100g": 165,
  "proteinPer100g": 31,
  "carbsPer100g": 0,
  "fatPer100g": 3.6,
  "fiberPer100g": 0,
  "matchedKeyword": "鸡胸肉",
  "weightG": 120,
  "confidence": 0.7,
  "confidenceLabel": "中等",
  "recognitionSource": "keyword_fallback"
}
```

## 日志与复核

`analysis_logs` 会保存：

- `recognitionSource`
- `modelProvider`
- `modelVersion`
- `confidence`
- `needReview`
- `candidates`

`review_tasks` 会保存同样的识别元数据，方便后台人工复核时判断来源和置信度。

## 当前限制

- 本阶段尚未解析图片内容。
- 图片会继续作为 `imageFileID` 保存和展示。
- 食物识别主要来自备注关键词和 `food_items` 匹配。
- 后续步骤会接入真实图片识别，并继续复用本契约。
