## 已验收通过的真实小程序流程

- 微信用户登录：已通过 `login` 云函数完成用户识别和资料读取。
- 身体资料填写 / BMI / 性别头像角色：首次进入可填写身体资料，自动计算 BMI；男性用户显示男性头像和男性角色，女性用户显示女性头像和女性角色。
- 记录餐食：记录页可选择餐次、上传或拍摄餐食图片、填写备注，并进入分析流程。
- `analyzeMeal` 识别营养：云函数可根据备注关键词和食物库返回识别食物、热量、营养估算、建议和风险提示。
- `saveMealRecord` 保存餐食：分析确认后可保存到云数据库 `meal_records`。
- `diary` 日记读取：日记页可按日期读取真实餐食记录，并映射到早餐、午餐、晚餐、加餐状态。
- `home` 首页汇总：首页可读取当天真实记录，汇总 kcal、蛋白质、碳水、脂肪、膳食纤维和健康评分。
- `report` 周报统计：周报页可读取 `getWeeklyReport` 云函数结果，展示本周统计、营养趋势和建议。
- `profile` 我的页真实资料：我的页读取 `userProfile` 云函数，不再显示 mock 用户名，资料和角色基于真实用户数据展示。

## 当前已知风险

- `debugInput` 仍保留在云函数返回中，便于测试阶段排查入参问题；正式上线前可移除或仅在管理员调试模式返回。
- mock 文件仍保留，但不覆盖核心真实链路；后续可逐步清理未使用的 mock 服务。
- 后台管理页还未正式开发，目前管理能力主要依赖云开发控制台和 `adminApi` 基础能力。
- AI 识别目前仍偏关键词 / `mock_keyword`，不是真实视觉 AI；图片本身尚未进入真实视觉识别模型。

## 下一阶段建议

- 开发后台管理页，用于查看用户、餐食记录、分析日志和复核任务。
- 增加食物库编辑能力，支持新增、修改、停用食物条目和别名。
- 完善 AI 复核任务流，对低置信度识别、无匹配图片、异常热量记录进行人工复核。
- 接入真实图片 AI 识别，结合图片、备注、用户确认结果生成更可靠的营养估算。
- 完善权限与管理员白名单，确认 `ADMIN_OPENIDS`、`ADMIN_SETUP_KEY` 和 `admin_users` 的管理流程。
- 上线前补充隐私与合规文案，明确产品提供的是饮食记录、营养估算和生活方式参考，不提供诊断、治疗或医学判断。
